About

Design thinking, turned into usable experiences.

I'm a UI/UX designer with practical, project-based experience turning user needs into clear and intuitive digital experiences. I focus on understanding the problem, creating user flows and wireframes, then refining visual interfaces through prototyping and feedback.

I care about the details that make an interface easy to understand and use — hierarchy, spacing, typography, responsive layouts, component consistency and usability. I'm currently completing my HNDIT diploma at SLIATE Badulla while building UI/UX projects like the one below.

BiteGo — Premium Mobile Delivery Experience

UI Design · UX Design · Figma · Prototyping · Responsive Design

A food delivery mobile app concept designed for Colombo, focused on premium dining, fast delivery, and a modern, intuitive user experience.

  • Designed user flows, mobile UI screens, reusable components, and an interactive product experience.
  • Applied color theory, typography, spacing, visual hierarchy, glassmorphism, and responsive design principles.
  • Created a practical live demo to demonstrate search, food filtering, favourites, cart interactions, offers, and order tracking.
  • Developed the project as a UI/UX case study and portfolio presentation with a clear visual direction and design system.

Golden Time — Watch Shop Website

Node.js · Express · HTML/CSS/JavaScript · JSON file storage · Multer

A full-stack e-commerce style website built for a watch retail client: a public catalog site for browsing and enquiring about watches, plus a private admin dashboard for managing the shop.

  • Designed the UI and built both the front-end and back-end — a REST API, file-based database, image upload, and authentication.
  • Kept the admin panel completely separate from the public site, so store management stays private and inaccessible to visitors.
  • Delivered a working system that lets the client manage products and customer enquiries independently, without needing a developer for routine updates.
